# Instituto Patas que Transformam

Projeto acadêmico de Front-end para uma ONG fictícia de proteção animal.

## Objetivo

Criar uma plataforma web responsiva para apresentar uma organização de proteção animal, divulgar projetos, incentivar adoções e permitir o cadastro de pessoas interessadas em voluntariado, lar temporário, doações e outras formas de ajuda.

## Tecnologias

- HTML5 semântico
- CSS3 responsivo, com abordagem mobile-first
- JavaScript puro (Vanilla JS)
- Sem frameworks ou bibliotecas externas

## Páginas

- `index.html` — início, apresentação da ONG, impacto, projetos, doações e contato.
- `projetos.html` — projetos de adoção, saúde, resgate e conscientização, com filtro interativo.
- `cadastro.html` — formulário completo para cadastro de voluntários/interessados.

## Funcionalidades JavaScript

- Menu mobile.
- Seleção interativa de valores de doação.
- Filtro de projetos por categoria.
- Máscara de CPF.
- Máscara de telefone.
- Máscara de CEP.
- Validação de CPF.
- Validação nativa do formulário HTML5.
- Validação de interesses selecionados.
- Mensagens de sucesso/erro.
- Simulação de envio do formulário de contato.

## Imagens

Os espaços de imagem foram deixados como placeholders visíveis com a indicação `INSERIR IMAGEM`.

Substitua esses blocos por imagens reais da ONG/projeto, preferencialmente em formatos otimizados como WebP e AVIF quando possível.

## Como executar

Abra `index.html` diretamente no navegador ou utilize uma extensão como Live Server no VS Code.

## Observação

Este é um projeto acadêmico. Os formulários são apenas demonstrações no front-end e não enviam dados para um servidor real.
